# Personal Academic Website

This is a GitHub Pages starter website for a PhD researcher at University College Dublin.

## Files

- `index.html` — main website
- `style.css` — website styling
- `cv.pdf` — replace with your CV
- `images/profile.jpg` — optional profile photograph

## Deploying to GitHub Pages

1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload `index.html` and `style.css`.
3. Add your CV as `cv.pdf`.
4. In **Settings → Pages**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Your site should appear at `https://YOURUSERNAME.github.io`.

## Before publishing

Replace:
- `Your Name`
- `your.email@ucd.ie`
- placeholder publication information
- Google Scholar / ORCID / GitHub / LinkedIn links
- CV
- profile initials/photo
